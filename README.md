🎓 PEMWEB_DATA_MAHASISWA

Aplikasi web untuk manajemen data mahasiswa menggunakan React + TypeScript, dibangun dengan Vite dan distyling dengan Tailwind CSS.

---

✨ Fitur Utama

- 🔐 Login pengguna
- 📋 Tampilan daftar data mahasiswa
- 📝 Form input/edit mahasiswa
- 📊 Dashboard mahasiswa

---

🧰 Teknologi yang Digunakan

| Teknologi     | Deskripsi                          |
|---------------|------------------------------------|
| React         | Library UI berbasis komponen       |
| TypeScript    | Superset JavaScript dengan tipe    |
| Vite          | Bundler modern dan super cepat     |
| Tailwind CSS  | Utility-first CSS framework        |
| ESLint        | Linter untuk menjaga kualitas kode |

---

🚀 Cara Menjalankan Proyek

```bash
 1. Clone repositori
git clone https://github.com/username/PEMWEB_DATA_MAHASISWA.git
cd PEMWEB_DATA_MAHASISWA

2. Install dependensi
npm install

3. Jalankan aplikasi
npm run dev

4. Akses di browser
http://localhost:5173
```
